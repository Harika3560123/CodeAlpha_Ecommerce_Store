Project Architecture & Features Implemented

Frontend Architecture

Handcrafted responsive HTML5, modern CSS with custom design system, and Vanilla JavaScript. Features dynamic AJAX cart adding, instant quantity updates, live toasts, and mobile navigation.

Django Backend

Robust Django 5 backend powering REST-like endpoints, session cart management, order calculation logic, authentication middleware, and WhiteNoise static asset serving.

Database & Models

Relational SQLite database modeling Categories, Products, Carts, CartItems, Orders, OrderItems, and UserProfiles with pre-seeded realistic items and Django Admin dashboard.
